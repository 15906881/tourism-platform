# @weblynk/blocks

Reusable content blocks for multi-tenant websites.

## Installation
npm install @weblynk/blocks

## Requirements
- React 18+
- @weblynk/ui package

## Usage
import { Hero, Gallery } from '@weblynk/blocks';
import { RoomCard } from '@weblynk/blocks/hospitality';

## Blocks
Shared: Hero, Gallery, Reviews, ContactForm, LocationMap, Hours, FAQ
Service Booking: AvailabilityCalendar, ServiceCard, BookingForm
Hospitality: RoomCard, AmenitiesList, PricingTable
Professional: TeamMember, Portfolio, CaseStudy
Food: MenuItem, MenuSection, ReservationWidget
